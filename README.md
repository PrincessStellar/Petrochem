
## Create: Petrochem
> Create Petrochem is a Minecraft mod and addon for Create mod that introduces **_petroleum_** extraction and refining.

## Links
- [Curseforge](https://www.curseforge.com/minecraft/mc-mods/create-petrochem)
- [Discord](https://discord.com/invite/aZgTGRgbbS)

## Machinery

This mod adds the following machines:

- **Pumpjack** - animated multiblock petroleum extractor.
- **Electrolyzer** - a modified mixer that uses electricity to perform electrolysis.
- **Distillation Tower** - a multiblock tower to perform distillation in 3 different methods.
- **Flarestack** - a simple burner to discard fluids.
- **Gasoline Engine** - portable and powerful rotation generator - ~49kSU
- **Diesel Engine** - compact and super powerful rotation generator - ~130kSU
- **Gas Turbine** - electric generator powered by LPG
- **Steel pipe and derivates** - steel variant of pipe, pump, valve and smart pipe.
- **Steel fluid tank** - steel variant of the Create fluid tank, base of the distillation tower.

## Modes:

### Base

simpler, straightforward recipes to get going:

- Dessalinization
- Flash, Atmospheric and Vacuum distillation

### Expert - ~~gregtech mode~~ (upcoming)

in-depth petroleum refining recipe graph for experts, based on real life processes and adapted into a create addon. processes include but not limited to:

- Desalinization
- Flash, Atmospheric and Vacuum distillation
- Hydrodesulfurization
- Mercaptan Oxidation
- Alkylation
- Delayed coking
- Propane deasphalting
- _about 5 more_…

## Why not X?

- TFMG - Ever tried getting any deep into tfmg? Glitches and unexplained mechanics are plentiful, the recipes are too simple (does not yield a cool refinery), and they ruined the pumpjack's aesthetic. No, 0 lines of code came off it.
- Diesel Generators - It's fine if you don't want anything fancy, this addon provides a much deeper (even in base mode) challenge and the refinery looks cooler.

## Dependencies

- Create
- Create: Alloyed
- KubeJS Create (**optional**) - required if using KubeJS
- \[Some Wire Mod\] - The mod by now does _not_ include it's own wires, therefore use a mod such as Create: Crafts & Additions or Create: New Age for wires.
## Modpacks
